# Lyme AI Architecture

## Vision

Lyme AI is a collection of specialized AI agents working together to accelerate evidence-based Lyme disease research.

## Core Agents

### Research Agent
Searches and analyzes scientific publications.

### Evidence Agent
Evaluates the quality and strength of evidence.

### Clinical Agent
Summarizes clinical guidelines.

### Trial Agent
Tracks ongoing and completed clinical trials.

### Patient Agent
Explains scientific findings in patient-friendly language.

### Physician Agent
Provides technical summaries for healthcare professionals.

### Translation Agent
Translates knowledge into multiple languages.

### Sentinel Agent
Monitors newly published research.

---

Together these agents form the Lyme AI ecosystem.
