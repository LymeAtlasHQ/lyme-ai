# Lyme AI Knowledge Base

This directory contains the scientific knowledge base used by Lyme AI.

## Sources

The system will prioritize evidence in the following order:

1. CDC
2. WHO
3. IDSA
4. ILADS
5. Peer-reviewed publications (PubMed)

## Goals

- Evidence-based answers
- Source attribution
- Scientific transparency
- Continuous updates

This directory will grow into the central knowledge repository for Lyme AI.
